在 CVAT 中怎样才算完成审核？
  1. 进入作业（Job）。打开下方 CVAT 工作区，在任务中进入每个作业，逐张检查图片。
  2. 修正并补齐。删除误检，调整框和类别，补画漏掉的目标；没有候选框的图片也要检查。这里只支持矩形检测框。
  3. 保存，再完成验收。保存修改（Save）后，将每个作业的阶段设为“验收（acceptance）”，状态设为“已完成（completed）”。多个作业需要逐个完成。
  4. 回到本页确认并回传。填写审核者并确认漏标检查，系统核验后才会更新这里的审核统计。

只在 CVAT 保存不会回传结果；勾选本页确认也不会替你完成 CVAT 验收。

需要新增类别时，在本页底部创建类别版本，保留已有编号、只追加新类别；回传时选择该版本。
